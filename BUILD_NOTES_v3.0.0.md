# NEXORA AI v3.0.0 — Build notes

## Base preserved
Built from the archived `NEXORA-MATERIAL-LAB-v2.0.0.zip`, preserving the React/Vite frontend, FastAPI backend, 3D country globe, AI country research, Ollama/OpenAI/Gemini provider support, production dashboard, evidence ingestion, material catalogue, 118-element periodic table, OCR, CSV export, extraction comparison and Windows scripts.

## Added
- Repositioned navigation and product naming around the Earth Intelligence System.
- Added Satellite Vision with trusted Earth-observation/geological data portals and an interpretation checklist.
- Added DeepCore Explorer with selectable crust, mantle, outer-core and inner-core educational layers and an exploration workflow.
- Added Global Markets research module with commodity selection, authoritative publisher links and market-analysis checklist. It deliberately does not invent live market quotes.
- Added NEXORA Academy topics and an interactive knowledge check.
- Added these modules to the command-center landing page and NEXORA Guide intent routing.
- Updated version metadata and documentation.

## Known scope limits
- Satellite Vision opens external portals; it is not a proprietary satellite image processing pipeline.
- DeepCore is a schematic educational visualization, not a true 3D geophysical model.
- Global Markets is a source-linked research hub, not a live price feed or trading terminal.
- Academy currently contains a starter lesson index and one interactive quiz question.
- No new deposit coordinates or country reserve values have been fabricated.
