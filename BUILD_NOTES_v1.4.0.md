# NEXORA Material Lab v1.4.0

## Country intelligence update
- Expanded geological setting, geological history and geological overview for all 20 country seed records.
- Added geological provinces/regions and major stratigraphic or igneous units where relevant.
- Expanded resource-sector and mining/processing industry descriptions.
- Added country-specific source discovery links and explicit provenance/limitations.
- Updated API normalization so the country endpoint returns the new fields.
- Updated frontend status and geological-context display.

## Evidence boundaries
- This is a qualitative country-intelligence expansion, not a completed global deposit database.
- Commodity-specific production, reserves and resources remain marked not curated unless supported by a dated, claim-specific source.
- The globe can display countries outside the 20 curated seed profiles; those still receive an explicit not-curated fallback.
- National authority portals are discovery links, not claim-level citations.
